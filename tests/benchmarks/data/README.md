# Vendored benchmark data

Three documents from [nativejson-benchmark](https://github.com/miloyip/nativejson-benchmark),
which is what [serde_json](https://github.com/serde-rs/json-benchmark),
[simdjson](https://github.com/simdjson/simdjson),
[RapidJSON](https://rapidjson.org/md_doc_performance.html) and
[orjson](https://github.com/ijl/orjson) benchmark on, so numbers taken on them are comparable
with those projects'.

- `twitter.json` — a Twitter API search for the character meaning "one" in Japanese and
  Chinese, which is why 5.6% of its bytes are non-ASCII
- `canada.json` — the Canadian border as GeoJSON, roughly 111,000 floating-point coordinates
  and almost nothing else
- `citm_catalog.json` — a concert-ticketing catalogue: a large, deeply nested object graph of
  small records

## Checking them

They are committed `xz` compressed, because this repository caps added files at 500 KB and
`canada.json` gzips to 592 KB. That makes them unreadable in a diff, so nothing about them has
to be taken on trust. `../vendored_documents.py` records, for each one, the URL it came from,
the SHA-256 of the document and the SHA-256 of the compressed file.

Verify the committed files against those hashes, offline:

```bash
python -m tests.benchmarks.vendored_documents --check
```

Rebuild them from upstream and confirm the result is byte-for-byte what is committed:

```bash
python -m tests.benchmarks.vendored_documents
```

Add `--write` to replace the files. `test_vendored_documents_match_upstream` runs the offline
check in CI.

Compression is `lzma` at preset 9 with a CRC-64 check, with the filter chain pinned in the
script rather than taken from a CLI's defaults. It is reproducible: the same input gives the
same bytes on Linux x86_64 and macOS arm64, and matches `xz -9`.

## The other documents

`i18n_users`, `catalog` and `event_log` are not vendored: they are generated by
`../generate_json_shape_data.py` on first run and stay gitignored, which is how
`north_star_data.json` is handled. Generation is seeded, so it is byte-identical between runs.
